# GCET Student Portal — Web Frontend

This directory contains the Vite-based React web client for the GCET Student Portal prototype (Phase 1B).

## Overview
- **Framework:** React 19 + Vite
- **Language:** JavaScript
- **Default Dev Port:** `http://localhost:5173`
- **Backend Service:** Connects to FastAPI REST backend (`http://127.0.0.1:8000/api/health`)

## Quick Start

```powershell
# 1. Install dependencies
npm install

# 2. Run the Vite development server
npm run dev

# 3. Build for production
npm run build

# 4. Lint code
npm run lint
```

For complete full-stack environment setup, backend instructions, and architectural guidelines, refer to the root [README.md](../README.md).
